# Конвертер азбуки Морзе

Веб‑приложение на Go для конвертации текста в азбуку Морзе и обратно. Проект демонстрирует работу с HTTP‑сервером, обработку HTML‑форм и файлов, маршрутизацию и использование вспомогательных пакетов.

## Функциональность

Приложение позволяет:
* загружать текстовый файл или файл с кодом Морзе через HTML‑форму;
* автоматически определять тип содержимого (текст или код Морзе);
* конвертировать содержимое в противоположный формат (текст ↔ Морзе);
* сохранять результат конвертации в новый локальный файл;
* отображать результат конвертации пользователю.

## Технологии

* Язык программирования: Go (Golang)
* Стандартная библиотека Go: `net/http`, `log`, `strings`, `time`, `filepath`
* Вспомогательный пакет: `pkg/morse` (предоставлен для конвертации)

## Пакеты

### `server`

Отвечает за создание и настройку HTTP‑сервера.

**Реализует:**
* структуру сервера с полями для логгера (`log.Logger`) и HTTP‑сервера (`http.Server`);
* функцию создания сервера и роутера;
* регистрацию хендлеров в роутере;
* настройку параметров сервера:
    * порт: `8080`;
    * таймауты: чтение — 5 с, запись — 10 с, ожидание — 15 с.

### `service`

Содержит логику определения типа данных и их конвертации.

**Функция:** `AnalysisAndConvert(input string) (string, error)`

**Логика работы:**
1. Анализирует входную строку.
2. Определяет, является ли содержимое кодом Морзе или обычным текстом (использует пакет `strings`).
3. Если текст — конвертирует в код Морзе с помощью `morse.ToMorse()`.
4. Если код Морзе — конвертирует в текст с помощью `morse.ToText()`.
5. Возвращает результат конвертации или ошибку.

### `handlers`

Реализует HTTP‑хендлеры для обработки запросов.

## Запуск

1. Данные пользователя уже определены в пакете main
2. Убедитесь, что у вас установлен Go (версия 1.17+).
3. Клонируйте репозиторий
4. Откройте терминал в папке с файлом `main.go`.
5. Запустите командой:

   ```bash
   go run main.go

6. Откройте в браузере: http://localhost:8080
